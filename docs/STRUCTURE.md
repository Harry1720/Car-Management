# Project Structure

## Frontend (/public)

- **/assets**: Static resources
  - **/css**: Stylesheets
  - **/js**: JavaScript files
  - **/images**: Images and icons
  - **/fonts**: Font files
  
- **/components**: Reusable UI components
  - **/navigation**: Navigation bars
  - **/footer**: Footer components
  - **/forms**: Form components
  
- **/pages**: Main pages by feature
  - **/home**: Homepage
  - **/about**: About VinFast pages
  - **/products**: Car product listings
  - **/deposit**: Deposit forms for each car model
  - **/charging**: Charging station information
  - **/policy**: Policy documents
  - **/promotion**: Promotional content
  - **/admin**: Administrative interfaces

## Backend (/src)

- **/config**: Configuration files
- **/controller**: Request handlers
- **/routes**: API routes
- **/test**: Unit and integration tests
